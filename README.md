## ❓ 作業問題回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？
- **為什麼以 3 人計算**：測試一整理後的桌遊串列為 `['amy', 'ben', 'amy', 'cora']`，其中 `'amy'` 出現了兩次，代表同一位參加者重複報名。依活動規則，同一人在同一場活動只算一位參加者且只收一次費用，去重後為 `{'amy', 'ben', 'cora'}`，共 3 人，因此桌遊費用為 $3 \times 120 = 360$ 元。
- **拆成 `list` 與轉成 `set` 的保留與失去**：
  - 拆成 `list`：**保留**了原始報名的先後順序與重複出現的紀錄，但因為有重複元素，不能直接當作不重複參加者人數來計費。
  - 轉成 `set`：**保留**了不重複的元素集合，方便做交集、聯集、差集與計算不重複人數，但**失去**了原本的排列順序與重複報名次數，且集合本身沒有索引順序，顯示前需再排序。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。
- 在測試三中，桌遊去重集合 $B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$ 與電影去重集合 $M = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$ 完全相同，因此聯集 $B \cup M = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，總不重複人數為 $|B \cup M| = 3$ 人。
- 但「報名人次」是兩場各自去重後的人數相加：$|B| + |M| = 3 + 3 = 6$ 人次（因為這 3 人兩場都參加）。
- 費用則是兩場分開計費再相加：
  - 桌遊應收：$3 \times 120 = 360$ 元
  - 電影應收：$3 \times 80 = 240$ 元
  - 總應收：$360 + 240 = 600$ 元。
